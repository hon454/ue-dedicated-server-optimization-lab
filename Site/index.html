서버는 한 프레임에 무엇을 보내는가

언리얼 엔진 Dedicated Server는 프레임마다 모든 액터를 훑어, 어느 클라이언트에게 무엇을 보낼지 정한다. 아래에서 최적화 기법을 하나씩 켜면, 서버의 일이 얼마나 줄어드는지 볼 수 있다.

UE5 Dedicated Server 최적화 실험실의 측정을 바탕으로 만들었다.

실제 서버에서 측정한 값

같은 시나리오를 세 번 실행한 중앙값이다.
이 페이지의 숫자를 읽는 법
  • "측정"이라고 적힌 값만 실제 서버에서 측정했다. 근거는 각 글의 측정 기록에 있다.
  • 지도와 흐름의 숫자는 이 브라우저에서 도는 모형이 센 값이다. 모형은 엔진의 기본 리플리케이션 순서를 따른다.
  • 맵 크기, 액터 수, 플레이어의 자리와 경로, 150m는 실제 값이다. 자원 노드와 NPC의 위치는 예시다.
  • 모형은 서버 프레임 간격을 측정값에서 가져온다. 기준선의 서버는 30Hz를 지키지 못해서 지도가 느리게 움직인다.
  • 모형은 플레이어 같은 다른 액터, 우선순위 정렬, 패킷 조립을 다루지 않는다.
