# 개발/테스트 환경 사양

포트폴리오의 모든 빌드, 실행, 측정은 아래 Windows PC 한 대에서 수행한다. 별도 Linux 환경은 사용하지 않는다.

## 하드웨어

| 항목 | 사양 |
| --- | --- |
| CPU | AMD Ryzen 9 5950X (16코어 / 32스레드) |
| RAM | DDR4 64GB |
| GPU | NVIDIA GeForce RTX 4090 |

## 소프트웨어

| 항목 | 내용 |
| --- | --- |
| OS | Windows |
| 엔진 | Unreal Engine 5.8.3 (소스 빌드) |

## 측정 시 전제

- Dedicated Server와 모든 클라이언트(또는 봇)가 같은 PC에서 실행된다.
- 따라서 서버와 클라이언트가 CPU/메모리를 나눠 쓰며, 네트워크는 루프백이다. 지연/손실은 엔진의 패킷 시뮬레이션 설정으로 재현한다.
