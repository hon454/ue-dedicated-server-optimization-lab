# 채용공고: 언리얼5 오픈월드 멀티플레이 / Dedicated Server 프로그래머

## 담당업무

- 언리얼5 엔진 기반의 오픈월드 멀티플레이 게임 개발
- 언리얼5 엔진 Dedicated Server 최적화 및 기술 지원

## 자격요건

- 실무 경력 5년 이상이신 분
- C/C++에 능숙하신 분
- 언리얼5 Dedicated Server 기반 개발 및 최적화 경험이 있으신 분

## 필요역량

- 언리얼 엔진5에 대해 깊은 이해가 있으신 분
- 문제의 원인 분석과 해결 능력이 있으신 분

- 다양한 OS/플랫폼에서 프로파일링 수행 및 최적화를 해본 경험이 있으신 분
