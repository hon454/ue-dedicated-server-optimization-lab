# ADR-0003: 기준선에서 엔진 기본 관련성 판정을 끈다("무법지대")

- 상태: 승인됨
- 날짜: 2026-10-01
- 출처: [설계 문서](../Planning/2026-10-01-short-term-portfolio-design.md) 6절 "기준선의 정의"

## 맥락

레거시의 `AActor`에는 기본 컬 거리가 있다(`SetNetCullDistanceSquared(225000000.0f)`, `Actor.cpp:312`, 150m). 아무 설정 없이 만든 액터도 이미 거리 기반 관련성 판정을 받는다. 엔진 기본값을 그대로 기준선으로 쓰면 "최적화가 전혀 없는 상태"가 아니다.

## 결정

기준선에서 자원 노드와 AI NPC에 `bAlwaysRelevant = true`를 준다(`LabResourceNode.cpp`, `LabNpc.cpp`의 생성자). 모든 액터를 모든 플레이어에게 보내는, 가장 단순한 구현을 출발점으로 삼는다.

## 고려한 대안

| 대안 | 버린 이유 |
| --- | --- |
| 엔진 기본값을 기준선으로 쓰기 | 출발점에 이미 관련성 판정이 들어 있어서, 관련성이 비용을 얼마나 줄이는지 보여 줄 수 없다 |
| 컬 거리 값을 조정하는 실험 | 기본값 복원과는 별개의 실험이라 백로그에 둔다 |

## 결과

- 포스팅 1에 이 기준선이 의도적으로 만든 인위적인 출발점이라는 사실과 이유를 적는다.
- 포스팅 2의 개선은 "엔진 기본 동작의 복원"이고, 그 뒤 포스팅의 개선은 "기본 동작 위의 개선"이다. 포스팅과 README의 최종 정리에서 두 종류의 변화를 나눠 적는다.
- 이 사실은 측정의 한계(설계 문서 8.5절)에도 들어간다.
