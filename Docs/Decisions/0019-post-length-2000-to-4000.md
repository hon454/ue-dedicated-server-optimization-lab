# ADR-0019: 포스팅 본문의 분량을 글자 수 2,000\~4,000자로 넓힌다

- 상태: 승인됨
- 날짜: 2026-10-06 (사용자 결정을 에이전트가 옮김)
- 출처: 태스크 25(포스팅 8 초안), 2026-10-06 사용자와의 논의. [ADR-0018](0018-post-length-in-characters.md)을 대체한다

## 맥락

ADR-0018은 본문의 분량을 글자 수 2,500\~3,500자로 정했다. 세는 법은 그대로 두고 범위만 다시 정한다. 그 범위에서는 이미 쓴 글 세 편이 벗어났다: 테스트베드 글 2,360자, 포스팅 6 3,545자, 포스팅 7 3,527자(ADR-0018의 표). 포스팅 8의 "배운 것과 한계"에 엔진 기본값 설명을 더하면 3,500자에 가까워진다.

## 결정

본문의 분량은 ADR-0018과 같은 방법으로 센 글자 수로 2,000\~4,000자다. 4,000자를 넘으면 수치와 단서를 측정 기록으로 옮긴다. 사용자가 정했다(2026-10-06). 포스팅 0\~8은 모두 이 범위 안에 든다.

독자가 3\~5분에 읽는다는 목표와 문장 규칙은 그대로다. 범위가 넓어진 만큼 길이는 위 상한보다 문장 규칙으로 다스린다.

## 고려한 대안

| 대안 | 버린 이유 |
| --- | --- |
| 2,500\~3,500자(ADR-0018) | 이미 쓴 글 세 편이 벗어나고, 포스팅 8에 설명을 더할 여유가 적다 |
| 2,700\~3,700자 | ADR-0017의 바이트 범위를 그대로 옮긴 값이다. 사용자가 더 넓고 기억하기 쉬운 값을 골랐다 |
